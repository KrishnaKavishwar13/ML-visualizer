# 🧠 Lightweight ML Model Visualizer

A beginner-friendly, lightweight Streamlit app to upload any CSV file, visualize the dataset, and train simple ML models (Logistic Regression, Decision Tree) — built specially for low-end PCs (4GB RAM, i3 7th Gen).

---

## 🚀 Features

- 📂 Upload CSV dataset
- 🧐 Preview data & select target column
- ⚙️ Drop missing values and encode categorical features
- 🤖 Train models: Logistic Regression or Decision Tree
- ✅ Save the trained model in .pkl format
- 📈 View accuracy, confusion matrix & classification report
- ✅ Works smoothly on low-spec machines (4GB RAM, i3)
- 📊 Test the model on your inputs

---

## 🧰 Tech Stack

- Python 3.x
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib
- Pickle
